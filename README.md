A program that writes one original AI out-of-office auto-reply to `/output/entry.txt` for make.fun's The Funniest AI Out-of-Office Reply bounty. Pure Python stdlib, deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
